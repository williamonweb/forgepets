FORGEPETS v11.0 — BASE DE QUALIDADE

ALTERAÇÕES
- A entrada no sistema não exibe mais erro genérico quando uma API secundária falha.
- Tutores e Pets são sincronizados separadamente; a falha de um módulo não bloqueia o outro.
- Falhas automáticas de inicialização ficam registradas no console, sem assustar o usuário.
- Novo sistema de notificações com tipos: sucesso, informação, aviso e erro.
- Notificações ficam no canto superior direito e não são cobertas pelo Forge Connect.
- Forge Connect fica menor, afastado do conteúdo e oculto durante modais.
- Textos de sessão das APIs corrigidos para português.

INSTALAÇÃO
1. Extraia por cima da pasta clonada.
2. Execute: npm ci
3. Execute: npm run build
4. Execute: git add .
5. Execute: git commit -m "v11.0 melhora estabilidade e notificacoes"
6. Execute: git push origin main
